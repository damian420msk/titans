# Титаны

Браузерная 3D-игра: дуэль полубогов-титанов на парящих островах. Бросай небесные камни по плитам острова врага, пока он не рухнет вниз.

```bat
npm install
npm run dev        :: открыть http://localhost:5173
npm test           :: правила боя и бот (node:test)
npm run build      :: проверка типов + сборка
```

Управление. ПК: WASD, ЛКМ бросок (держи для кручёного/мощного), ПКМ или Esc отмена, Пробел ремонт. Телефон (горизонтально): левый палец ходьба, правый прицел и бросок, сдвинуть палец на ✕ отмена, зелёная кнопка ремонт.

Структура: `shared/` правила (чистый TS, без Babylon), `client/play/` отрисовка и ввод, `public/art/` модели и фон, `tools/concept/` сцена для концептов, `docs/` документы. Подробнее в `CLAUDE.md`.
