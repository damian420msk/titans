# Журнал решений

- 2026-10: патчим прототип, а не переписываем с нуля, но боевой слой переписан: старый клиент держался на обзоре мышью и прицеле по центру экрана.
- Камера фиксирована на остров врага; прицел по клетке пальцем/мышью; отмена броска без траты камня.
- Ловля снарядов убрана. Ремонт оставлен: 1,0 с трещина, 2,2 с дыра, 1 камень.
- Бросок: обычный (0–0,9 с, 1 клетка), кручёный (0,9–2,6 с, 2 клетки), мощный (от 2,6 с, 2 клетки, урон 2). Откат 1,1 с, до 3 камней, автопополнение у арсенала 0,7 с/камень.
- 3 жизни, падение отнимает жизнь, респаун на защищённой клетке [4,0]. Матч 3 мин, при ничьей по жизням побеждает остров с большим HP.
- Попадание по титану: нокдаун 0,55 с, отброс 0,75 клетки (мощный 1,25) к тылу острова.
- Сеть (Colyseus) убрана из репозитория до этапа «рейды»: пока бой с ботом. Старый код в истории git (коммит d2874df).
- Прыжок, донаты, потолок прокачки: отложены.
- 2026-10: меню — один экранный менеджер `client/play/menu.ts` (чистый DOM, без backdrop-filter ради слабых телефонов); при открытом меню 3D-сцена не рисуется. Онлайн-экраны получают данные через `setRooms/renderRoom`, сетевой слой подключим позже.
- 2026-10: онлайн-дуэли: обычный WebSocket (`ws`) на Render (free) вместо Colyseus: меньше зависимостей, протокол под контролем. Сервер авторитетен и крутит `Battle`, клиенты шлют намерения, снимки 20 Гц. Гость получает зеркальный снимок (стороны меняются, мир поворачивается на 180°), поэтому каждый видит себя «снизу». Рейтинг позже в Supabase. Репозиторий публичный только ради бесплатных GitHub Pages.
- 2026-10: клиент онлайн: свои ходьба и заряд бросок предсказываются локально, остальное берётся из снимков; позиция правится только при расхождении больше 0,35 м. Броски и ремонт выполняет сервер.
- 2026-10: онлайн, найдено на первом тесте с телефона: сервер не зеркалил стик гостя (гость видит мир повёрнутым на 180°), из-за чего клиент и сервер тянули титана в разные стороны. Исправлено + тесты. Сверка позиции вынесена в `shared/predict.ts` и проверяется против настоящего сервера с имитацией задержки и низкого fps (`tests/predict.test.ts`). Онлайн-симуляция идёт в реальном времени (dt до 0,25 с), офлайн как раньше (до 0,05 с).
- 2026-10-25: мета-игра. Профиль на сервере по хешу случайного токена (без аккаунтов), гости без токена не сохраняются. Рейтинг Эло, старт 1000, лиги Бронза/Серебро/Золото/Платина/Алмаз (0/1100/1250/1450/1650). Монеты: бот 20–60, онлайн 20–60, подарок дня 50. Анти-фарм: интервал 25 с для ботов, 6 боёв/час на пару для онлайна. Причина: игра должна цеплять возвращением, но без накрутки.
- 2026-10-25: улучшения (мешок +1 камень, руки −7% откат, ноги +4% ходьба, добытчик −12% набор камней, крепкие плиты +1 удар) заданы как `Mods` на сторону в `Battle`, а не правкой rules JSON: базовый баланс не тронут, апгрейды максимум +2/+21%/+12%/+36%/+1 плита, чтобы мастерство решало больше денег. Цены в `shared/progress.ts`. Косметика только цвет (тонировка), на баланс не влияет.
- 2026-10-25: камера. Добавлен «взгляд назад» (зажать C/Shift на ПК, кнопка 👁 на телефоне): камера уходит вперёд-вверх и показывает свой остров, стик при этом инвертируется под вид, бросок и прицел отключены. Обычная камера по-прежнему на острове врага. Причина: при ходьбе назад не видно своих разбитых плит.
- 2026-10-25: онлайн-соперник рисуется со сглаживанием (экспоненциальный догон k=16/с, сброс при скачке >4 клеток или падении). Логика боя не меняется, только визуальная позиция.
