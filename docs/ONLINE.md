# Онлайн

Локально: `npm run server` (порт 8787) и `npm run dev`. Клиент на localhost сам подключается к `ws://localhost:8787`. Свой адрес сервера: `?server=wss://...` в ссылке.

Прод: Render, Blueprint `render.yaml` (сервис `titans-server`, free, Frankfurt). Клиент по умолчанию идёт на `wss://titans-server.onrender.com` (`SERVER_FALLBACK` в `client/play/online.ts`); если Render выдал другой адрес, поправить константу или задать `VITE_SERVER_URL` при сборке.

Free-тариф засыпает после 15 минут простоя, первое подключение занимает до минуты: меню показывает это и само повторяет попытки.

Протокол: `shared/net.ts`. Клиент шлёт намерения (`move`, `begin`, `target`, `release`, `cancel`, `repair`), сервер каждые 3 шага (20 Гц) шлёт снимок + события. Тесты: `tests/net.test.ts` (снимки и зеркальность правил), `tests/lobby.test.ts` (комнаты, пароли, бой).

## Профили, монеты, рейтинг

Игрок = случайный токен в localStorage (`titans.token`). Сервер хранит только хеш токена (sha256, 32 символа) как id профиля. Монеты, рейтинг, улучшения и скины считает и хранит сервер, клиент лишь показывает (`shared/progress.ts` общий для обоих). Без сервера меню показывает последний сохранённый профиль, бой с ботом работает, награда придёт при следующем подключении.

- Бой с ботом: награда монетами (лёгкий 20/5, средний 35/10, сложный 60/15; победа/поражение), не чаще одного боя в 25 с.
- Быстрый бой и рейтинговая комната: Эло + монеты (60/20/30). Подбор по рейтингу, окно 150 + 40 за каждую секунду ожидания, до 30 с.
- Дружеская комната: только монеты. Против фарма: не больше 6 засчитанных боёв в час с одним и тем же соперником.
- Подарок дня: +50 монет, день считается по МСК.
- Улучшения и косметика покупаются на сервере; в бой улучшения попадают через `Battle([mods0, mods1])`, поэтому онлайн их применяет сервер, а не клиент.

### Хранилище (Supabase)

Пока переменные не заданы, профили живут в памяти сервера и пропадают при перезапуске (Render free засыпает и перезапускается).

1. supabase.com → New project (бесплатный тариф).
2. SQL Editor, выполнить:
   `create table profiles (id text primary key, rating int not null default 1000, games int not null default 0, data jsonb not null, updated_at timestamptz default now()); alter table profiles enable row level security;`
3. Project Settings → API: скопировать Project URL и ключ `service_role` (секретный, только на сервере; в клиент и в репозиторий не класть).
4. Render → titans-server → Environment: `SUPABASE_URL` и `SUPABASE_KEY`. Сохранить, сервис перезапустится.
5. `GET /health` покажет тип хранилища.

Локально можно писать профили в файл: `DATA_FILE=./profiles.json npm run server`. `FAKE_LAG_MS=120` добавляет искусственную задержку для проверки предсказания.

### Обрыв связи посреди боя

Игрок с сохранённым профилем (токен) при обрыве теряет место не сразу: сервер держит его 15 секунд (`GRACE_MS` в `server/lobby.ts`), титан стоит на месте, сопернику приходит `away` («Соперник потерял связь»). Клиент сам переподключается каждые 0,7 с, сервер по токену возвращает место (`start` + свежий снимок). Не вернулся за 15 секунд: поражение, как при выходе. Гость без токена вылетает сразу. Сдаться: меню паузы, это немедленное поражение.
