# TITANS — единый набор блоков A/B/C, v03
24 октября 2026. Объединяет A v02 и B/C v01. Старые отдельные задания заменены CODEX_TASK_RU.md из этого архива: подключать сразу A/B/C.

## Состав
Каждая папка A, B, C содержит models (3 GLB), textures, previews и tools.
A: Y-разлом, 3 обломка. B: диагональный разлом, 4 обломка. C: разветвлённый разлом, 5 обломков.
Состояния: intact — целый; cracked — после первого попадания; fragments — именованные обломки в собранном положении, для временного эффекта.
Встроенные текстуры 512×512 позволяют загрузить GLB без внешних ресурсов. Отдельные PNG нужны исходнику Blender.

## Размеры и геометрия
2,8×2,8×0,4 м; GLB Y-up, центр верхней плоскости (0,0,0), низ Y=-0,4. Все состояния имеют одинаковые внешние границы. geometry.json для Blender — Z-up; не применять дополнительный поворот GLB автоматически.
Небольшие сколы декоративны: логическая клетка остаётся квадратной. Первый удар — трещина с сохранением опоры; второй — полная дыра. Обломки не создают опору и коллизии.

## Вариативность
При создании поля каждая клетка получает равновероятный A/B/C и поворот 0/90/180/270°. Выбор стабилен на весь матч, включая восстановление тестового раунда. Новое поле/новый матч может получить новый набор. Оба клиента используют один серверный seed и глобальные координаты клетки либо серверные variantId/rotation. В локальной тренировке seed создаётся локально один раз.
Один вариант определяет всю последовательность целый → треснувший → его обломки. Случайность не меняет прочность, размер, попадания или исход раунда.

## Исходник и ограничения
Готового .blend нет. Скрипт tools/create_blender_source.py в каждой папке создаёт его локальным Blender; скрипты здесь синтаксически проверены, но не исполнены. Превью — программные рендеры реальных моделей, reference — художественный ориентир, не схема карты.
Все 9 GLB повторно проверены trimesh; итог в VALIDATION.json. Проверены конечность координат, ненулевые площади треугольников, встроенные изображения, число частей и размеры. Импорт Babylon, Blender, реальное освещение и телефон требуют локальной проверки. Не утверждать, что набор уже установлен в игру.
