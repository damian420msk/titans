# Яндекс Игры

Обёртка SDK: `client/play/yandex.ts`. Без SDK все вызовы пустые, игра работает как обычно (GitHub Pages, локально).

## Что уже подключено
- `LoadingAPI.ready()` после загрузки; `GameplayAPI.start/stop` на начале и конце боя.
- Реклама между боями (`interstitial`, не чаще раза в 90 с, не в первом бою) и кнопка «Удвоить награду» (`rewarded`) на экране конца боя. На время рекламы звук глушится (`sfx.hold`).
- Удвоение: клиент после просмотра шлёт серверу `bonus`, сервер повторяет последнюю награду один раз за бой (потолок 150). Сервер не видит рекламу, поэтому подделать запрос можно; цена вопроса только монеты, рейтинг не затрагивается.

## Как проверить без Яндекса
`?fakeads=1` в адресе: игра делает вид, что SDK есть, реклама длится 1,5 с.

## Что останется при релизе
1. Сборка `npm run build`, в архив положить содержимое `dist/` (index.html в корне), размер до лимита Яндекса.
2. Сервер Render остаётся отдельно: в консоли Яндекса разрешить внешние запросы (WebSocket на `titans-server.onrender.com`). Проверить, что Яндекс принимает внешний сервер для онлайн-игры; если нет, режим онлайн придётся отключить в версии для Яндекса.
3. Язык: интерфейс сейчас только русский; для международной версии нужны переводы.
4. Тест на SDK-версии в черновике (SDK Яндекса подставляет `/sdk.js` только внутри их iframe).
5. Мониторинг: логин игроков через Яндекс (опционально) вместо токена, чтобы прогресс переживал смену устройства.

## Требования Яндекса (сверено 2026-10-25 по документации)
- Модерация полная 3–5 рабочих дней плюс очередь; после отказа повтор через 24 ч, 2, 4, 8, 16 дней.
- Архив: `index.html` в корне, до 100 МБ, без пробелов и кириллицы в именах файлов, без абсолютных URL на S3 Яндекса.
- Реклама только через SDK, только в логических паузах, звук и игра на паузе на время показа; rewarded необязателен.
- Запрещены: ссылки на внешние сайты и призывы уйти на сторонние ресурсы (кнопку «Позвать друга» скрыть), регистрация на сторонних сервисах, вход иначе чем через Яндекс ID по действию игрока, нецензурные слова.
- Нужен гостевой вход с сохранением прогресса. Иконка и обложка не скриншоты игры.
- Не должно быть ошибок в консоли и предупреждения про WebGL; игра корректна при повороте и изменении окна; на ПК соотношение сторон поля не больше 2:1.
- Рейтинг игры в каталоге выше 30, иначе через 3 недели снимут.
- Шрифт Rubik сейчас грузится с Google Fonts, до отправки положить в сборку.
