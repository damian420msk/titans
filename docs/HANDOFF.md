## 1. Что за проект

Браузерная 3D-дуэль 1 на 1 «Титаны»: два титана-полубога на парящих островах из плит швыряют небесные камни по плитам острова соперника, пока тот не провалится в облака. Три жизни, матч до 3 минут. Платформы: ПК и телефон (горизонтально). Цель номер один: готовая игра 1.0 на нашем сайте; сборки под площадки (CrazyGames, Яндекс Игры, Google Play и др.) в самом конце (решение 2026-10-27, см. `docs/ROADMAP.md`).

Состояние: версия 0.9 альфа играбельна у нас (бой, бот трёх уровней, онлайн, профиль, монеты, рейтинг, магазин, обучение, задания, подарок). Жива на GitHub Pages и Render. Яндекс-сборка и модерация ещё впереди.

## 5. Репозиторий и команды

```
npm install
npm run dev        # клиент, http://localhost:5173 (на сервере сессии использовали 5199)
npm run server     # сервер дуэлей, порт 8787 (DATA_FILE=./profiles.json для локальных профилей)
npm run check      # tsc + все тесты (node:test), должен быть зелёным перед коммитом
npm run build      # tsc + vite build
```

Стек: TypeScript 7, Babylon.js 9.32, Vite 8, `ws`, Node ≥22.6 с `--experimental-strip-types` (в `shared/`, `tests/`, `server/` нельзя parameter properties, enum, namespace). 122 теста зелёные на 2026-10-26.

Структура (подробнее в `CLAUDE.md`):
- `shared/`: правила, чистый TS без Babylon и DOM, шаг 1/60 с, детерминированно. `battle.ts` правила, `bot.ts` бот (easy/normal/hard), `world.ts` сетка, `net.ts` протокол и снимки, `progress.ts` экономика, косметика, лиги (общая для клиента и сервера), `titans.ts` модели титанов, `platformKits.ts` и `platformStyle.ts` комплекты плит и раскладка стилей клеток.
- `server/`: `lobby.ts` комнаты, подбор, матчи (без сети, тестируется), `index.ts` HTTP + WebSocket, хранилище профилей (память / файл / Supabase).
- `client/play/`: `main.ts` цикл, HUD и «клей» (одна огромная функция, рерайт после 1.0), `world.ts` сцена и камера, `platform.ts` острова из GLB, `rig.ts` позы титана из клипов, `controls.ts` ввод, `menu.ts` экраны меню, `online.ts` сокет, `training.ts`, `quality.ts`, `yandex.ts` (SDK-обёртка, выключена), `icons.ts`, `hud.css`, `menu.css`.
- `public/art/`: `platform-skins-v01` (4 комплекта плит), `titans-v04` (синий титан), `titans-red-v01` (красный), `ui` (иконки и картинки магазина), `bg-v01` (спрайты неба, пока частично), `blocks-abc-v03` (старые плиты, только для `tools/concept`), `titans-v03` (старые).

Главные принципы (из `CLAUDE.md`, не нарушать):
1. Правила боя только в `shared/battle.ts` (+ `bot.ts`). Клиент читает состояние и шлёт намерения.
2. Числа из `rules_v01.json` и `map_9x11.json`; меняешь баланс, пишешь причину в `docs/DECISIONS.md`.
3. Каждое изменение механики сопровождается тестом.
4. Камера всегда смотрит на остров врага; прицел = клетка под пальцем/мышью; камера стоит на месте, пока держишь бросок.
5. Сервер авторитетен, клиент предсказывает свою ходьбу и заряд.

## 10. Секреты и безопасность

- Ключи (Supabase `service_role`, Meshy) не пишем в репо, чат и логи. Supabase-ключ лежит только в окружении Render; **перевыпустить** (раздел 8).
- Токен игрока (`titans.token` в localStorage) сервер хранит как sha256, 32 hex-символа. Гость без токена не сохраняется.
- Репозиторий публичный: в нём не должно быть ничего приватного. Исходники арта в `art-src/` не публикуются в сборку, но лежат в репо; крупные приватные пакеты держать у владельца на `D:\Titans_3D\`.

## 11. Технические ловушки (чтобы не наступать заново)

- Фоновые процессы (vite, сервер) в облачной сессии умирают между вызовами инструментов: запускать как `(setsid nohup npx vite --port 5199 --strictPort > log 2>&1 < /dev/null &)`; сервер убить `fuser -k 8787/tcp`.
- Playwright: `animations:'disabled'`, длинные таймауты, `waitUntil:'domcontentloaded'`; кликать через `page.evaluate(() => el.click())`, если swiftshader тормозит. Флаги тестов в localStorage: `titans.botwin`, `titans.train.skipped`, `titans.nofs`, `titans.train.done = '1'`. В консоли доступно `window.titans` (`battle, world, net, controls, setPause, state()`), у `world` есть `platformDiagnostics()`.
- Кадры swiftshader по 0,5–1 с: проверки по времени (затухания, окно реванша 40 с) делать синхронно с кадрами. Счётчик отрисовок `engine._drawCalls.current` накопительный.
- Профиль в сервере: id = первые 32 hex-символа sha256(токена); токен должен соответствовать `^[A-Za-z0-9_-]{16,64}$`. Для локальной проверки магазина запускай сервер с `DATA_FILE` и ставь `titans.token` в localStorage.
- Комплекты плит: комплект на остров, не на матч; палитра каймы (teal/coral) принадлежит физическому острову. Раскладка стилей клеток зависит от ключа `platform-v05.1|251025|arena-island-N|x,z` и не должна меняться.
- Магазин требует живого сервера (без него «Подключаемся…»).
- `public/art/blocks-abc-v03` нужен только `tools/concept/scene.ts`; не удалять без правки концепт-сцены.
