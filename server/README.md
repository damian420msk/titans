# Сервер NET-001

Node.js 24 + Colyseus 0.18. Комната `duel`, только два участника и приватный вход по коду; публичного подбора нет. `index.ts` запускает штатный WebSocketTransport, `duel-room.ts` валидирует намерения и считает `shared/Simulation` фиксированным шагом. `shared/net-schema.ts` содержит только публичное состояние, `shared/protocol.ts` — допустимые команды.

Из корня: `npm run dev` (оба процесса) либо `npm run dev:server` отдельно. Настройки и адреса описаны в корневом README. В dev клиент соединяется через прокси Vite `/net`, а не с localhost телефона. Серверный порт по умолчанию 2567, health — `/health`. Административных панелей, базы данных и аккаунтов нет.

Серверные проверки: `node --experimental-strip-types --test tests/network.test.ts`. Указанные в них дополнительные порты 2568/2569 должны быть свободны. Это отдельные реальные процессы и SDK-соединения; они не заменяют проверку физического телефона.
